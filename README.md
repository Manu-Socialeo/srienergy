# Sri Energy

Official website and resources for **Sri Energy**, providing PM Surya Ghar Muft Bijli Yojana eligible rooftop solar installations, solar panels, hybrid/on-grid inverters, and lithium battery storage in Mysore, Coorg, Mandya, Hassan, and surrounding regions in Karnataka.

[![Live Site](https://img.shields.io/badge/Live_Site-srienergy.vercel.app-blue)](https://srienergy.vercel.app/)

🔗 **Live URL:** [https://srienergy.vercel.app/](https://srienergy.vercel.app/)


## 🌐 Website Pages

- **Home (`index.html`)**: Complete rooftop solar solutions, PM Surya Ghar subsidy details, savings calculator, testimonials, FAQs, and quote request form.
- **Solar Panels (`solar-panels.html`)**: Mono Perc, TopCon, and bifacial solar panel options and specifications.
- **Solar Inverters (`solar-inverters.html`)**: On-grid, off-grid, and hybrid inverters with net-metering compatibility.
- **Lithium Batteries (`lithium-battery.html`)**: LiFePO4 energy storage solutions for residential and commercial backup.
- **Blog & Guides (`blog/`)**:
  - `pm-surya-ghar-subsidy-guide.html`: Step-by-step subsidy process & documentation.
  - `on-grid-vs-off-grid-vs-hybrid.html`: Solar system comparison guide.
  - `rooftop-solar-cost-mysore.html`: System pricing and ROI breakdown for Mysore.
  - `solar-pumpset-farmers-coorg.html`: Solar water pump systems for agricultural needs in Coorg/Kodagu.

## 🛠 Features

- **Responsive & Modern Design**: Clean UI optimized for desktop, tablet, and mobile browsers.
- **SEO & Schema Markup**: Rich structured data (`LocalBusiness`, `Electrician`, `OfferCatalog`, `FAQPage`, `BreadcrumbList`, Open Graph, and Twitter Cards).
- **Fast & Static**: Zero build step required, lightweight pure HTML/CSS/JS ready for deployment on GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

## 🚀 Running Locally

Open `index.html` directly in any modern web browser or serve via a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
